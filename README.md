A make.fun bounty entry. The program writes one line of horror — a single sentence under 200 characters — to `/output/entry.txt`.

## The line

> I found my own handwriting in a diary I never wrote, and tomorrow's page is already written.

## How it works

`main.py` (Python standard library only) validates the line against the bounty gate — 1 to 200 characters of UTF-8 text, not only whitespace — then writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
